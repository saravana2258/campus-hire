# Campus Portal Application

A web-based Campus Portal Application designed to manage student information, academic details, and campus activities efficiently. This system provides an easy-to-use platform for students, faculty, and administrators to access and manage campus-related information.

## 🚀 Features

- Student Management System
- Add, update, view, and delete student details
- Student profile management
- Course and department management
- Secure REST API integration
- Database storage and retrieval
- Responsive user interface
- Easy navigation and user-friendly design

## 🛠️ Technologies Used

### Backend

- Maven

### Frontend
